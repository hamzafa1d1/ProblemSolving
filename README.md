# C++ Problem Solving

Algorithm practice and competitive-programming solutions, including sorting/searching, sliding windows and scheduling exercises.

Each `.cpp` file is an independent solution. These are learning exercises rather than a reusable library or service.

## Compile one solution

```sh
c++ -std=c++17 -O2 Apartments.cpp -o apartments
./apartments
```

Provide input in the format expected by the corresponding problem. Check each source file for its particular assumptions; correctness and complexity are not independently verified for every solution.
